# Flutter & Dart Clean UI/UX Skill

## Mobile Standards
1. **Material 3 Theming & Layout**:
   - Modern Material 3ColorScheme, dynamic typography, elevated card hierarchy.
   - Smooth page transitions and bottom navigation bars.
   - Distinct empty, error, and loading state widgets.

2. **Native Integrations**:
   - **Camera & Image Picker**: For tenant ID document scanning, receipt capture, and maintenance photo attachments.
   - **Geolocator / GPS**: For property check-in verification, maintenance technician dispatch location tagging.

3. **Architecture & State Management**:
   - Clean folder structure: `features/`, `core/`, `shared/widgets/`.
   - Clear separation of Business Logic (Bloc / Riverpod / Provider) from UI presentation.
